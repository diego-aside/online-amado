# 온라인 아마도 (Online Amado)

중앙대 후문 요리주점 '아마도'(서울 동작구 흑석로 10)를 재현한 온라인 술집 월드.
친구들과 같은 테이블에 앉아 음식을 주문하고, 술을 가져다 마시며, 취기와 허기까지 공유하는 멀티플레이 공간.

> 비공식 팬메이드 재현입니다. 사진 속 인물이나 사장님을 특정하지 않으며,
> 사장님 NPC는 리뷰 언급에 기반한 캐릭터입니다.
> 영업시간·전화번호·현재 가격은 가게에 직접 확인하세요.

## 구성

- `index.html` / `style.css` / `main.js` — 정적 사이트 (Three.js r170 + Supabase Realtime + PeerJS)
- `menu.json` — 메뉴·가격 (출처: 2026-09-10 네이버 플레이스 메뉴판, 2026-11-13 라이브 확인)
- `VERIFY.md` — 빌드 검증 기록

사장님 대사·입장 인사 문구는 `main.js` 상단의 `OWNER_LINES` / `GREETING` 상수에서 관리합니다.

## 흐름 (v10 최종)

1. **입장** — 닉네임을 정하면 사장님이 먼저 맞이하고, 잠시 뒤 인사 선택지 3개("안녕하세요!" / "오늘도 왔어요!" / "처음 왔어요!")가 한 번 뜹니다. 고르면 사장님이 답인사를 합니다(20초 지나면 자동으로 사라짐, X로 닫기 가능).
2. **테이블 앉기 (로비 없음)** — 별도 로비 화면·테이블 목록·생성/합류 폼이 없습니다. 3D 테이블이나 의자를 직접 누르면 **앉기 다이얼로그**가 뜹니다(테이블 번호 · 현재 인원 예: 2/4명 · 비밀번호 입력란 · [앉기] · 닫기). 테이블 위에는 `테이블 N · 인원/4 🔒` 라벨이 떠 있습니다.
   - **빈 테이블(처음 앉는 사람)**: 비밀번호는 선택입니다. 숫자 4자리를 넣으면 그 테이블의 비밀번호가 되고, 비워두면 공개 테이블입니다. 처음 앉은 사람이 테이블을 지킵니다(keeper).
   - **사람이 있는 테이블**: 비밀번호가 설정돼 있으면 4자리를 입력해야 앉을 수 있고(틀리면 거부, 3회 틀리면 1분 잠김), 공개 테이블이면 입력 없이 바로 앉습니다. 비밀번호 여부는 디렉토리 채널의 `locked` 플래그로 판단합니다.
3. **앉으면** — 오른쪽 패널(메뉴판 / 채팅 / 가게 정보)이 자동으로 열리고, 일어서면 닫힙니다. 헤더의 `—`로 최소화하면 `☰ 메뉴` 알약 버튼만 남습니다.
4. **음식** — 메뉴판에서 담으면 *주문(ordered)* 상태가 되고, 15~25초 뒤 사장님이 서빙합니다(첫 음식 주문 시 알새우칩 서비스, 4입). 서빙되면 채팅 탭 상단 **테이블 위** 목록과 3D 테이블 위 접시에 나타납니다.
5. **술** — 메뉴판에서 주문하지 않습니다. 서쪽 벽의 **술 냉장고**(3D, 클릭)로 통행로를 따라 걸어가 13종 중 하나를 고르면 자리로 돌아오고, 테이블 위 목록과 계산서에 자동으로 올라갑니다. 테이블에 앉은 사람만 쓸 수 있습니다.
6. **먹기/마시기** — 테이블에 앉은 누구든 누를 수 있고 효과는 누른 사람에게만 적용됩니다. 음식 1개 = 4입(먹기 1회: 취기·허기가 내려감), 병 술 1병 = 4잔, 잔 술 1잔 = 1잔(술 마시기 1회: 취기가 오름, 무알코올은 그대로). 주문만으로는 취하지 않습니다.
7. **허기** — 0(배부름)~5(배고파 죽겠어요). 입장 시 2, 3분마다 +1. 4 이상이면 사장님이 음식을 권하고, 이때 술을 마시면 취기가 +1.5 오릅니다(빈속). 물 마시기·술 마시기는 허기에 영향이 없습니다.
8. **취기** — 0~5단계 동기화(물 −1, 화장실 −1, 안주 건네기 −0.5). 레벨 5는 무지개 토 🌈(60초 쿨다운).
9. 앉는 순간 줌형 격자 화면 — PeerJS 화상(카메라·마이크 기본 OFF), 테이블 공유 장바구니 + "내가 쏜다".

## HUD 게이지

취기(🍶)·허기(🍖)는 숫자 없이 **이모지 5칸**으로 표시합니다. 채워진 칸 = 현재 레벨 수(선명), 나머지 칸은 같은 이모지를 흐리게(opacity 0.25). 라벨('취기'·'허기')과 단계 문구는 그대로이고, 먹기·마시기 토스트와 버튼 title 도 수치 없이 말로만 안내합니다. 내부 수치 로직(레벨 0~5, 마시기 +1·빈속 +1.5, 먹기 −0.5·허기 −1)은 표시와 별개로 유지됩니다. 모든 UI 모서리는 12px(`--r`)로 통일(아바타·파티클 같은 원형 제외).

## 룸 레이아웃 (v10 최종)

주문대를 기준으로 세로로 긴 공간(7.2m × 14m). 위쪽(먼 쪽 끝)에 **주문대(사장님은 카운터 안)** 가 있고, **술 냉장고는 서쪽(왼쪽) 벽**에 붙어 문이 방 안쪽(동쪽)을 보고, **오른쪽 벽에 화장실 문**이 있습니다. 아래쪽(가까운 쪽 끝)은 **왼쪽에 통유리 접이문 입구**(스폰은 그 앞, 카운터를 바라봄), **오른쪽 벽에 벽걸이 에어컨**입니다. 테이블 6개(각 4석)는 2열 × 3행이며 테이블 긴 방향이 방 길이(z)와 같고 좌석은 테이블 양옆에 2개씩, 가운데 통로 2.4m는 비어 있습니다. 카메라는 입구 뒤쪽 위에서 카운터 쪽을 봅니다.

통유리 밖에는 인도 + 아스팔트 1차선 도로(중앙 점선)가 +x 방향으로 내려가는 **내리막길**로 이어지고, 배낭 색만 다른 학생 3명이 제자리 걷기 애니메이션과 함께 천천히 내려갔다가 위쪽으로 되돌아오는 루프로 오갑니다(기본 도형만 사용, 충돌 없음).

## 실시간 채널 (Supabase Realtime, 접두사 `amado-`)

- `amado-lobby` — 아바타 위치·자리(presence). 채팅·주문·취기·허기는 싣지 않음
- `amado-tables` — **테이블 디렉토리**(broadcast). 테이블 keeper(가장 먼저 앉은 사람)가 `{tid, count, seats, locked}` 를 만들 때·인원이 바뀔 때·5초마다 알리고, 새로 들어온 클라이언트는 `tables-req` 로 현재 상태를 받아옵니다. 앉은 사람이 로비 presence 에서 빠져도 테이블 점유가 사라지지 않게 하는 채널이며 코드·이름·채팅은 싣지 않음
- `amado-door-N` — 입장 비밀번호 확인(노크/승인). 비밀번호 없는 공개 테이블은 입력 없이 승인, 있는 테이블은 nonce+해시 증명으로만 확인(평문 미전송)
- `amado-table-N` — 채팅·주문·서빙(`serve`)·먹기(`eat`)·마시기(`drink`)·취기·허기·건배·무지개 토

`locked` 는 비밀번호 설정 여부일 뿐 비밀번호 자체는 싣지 않습니다. 로비 presence 는 아바타·접속 인원수(상단 배지)에만 쓰고, 테이블 고르기 UI 는 없습니다.

로비·디렉토리 채널은 연결이 끊기면 1→2→4→8초… 최대 30초 간격으로 계속 재구독하고, 재구독하면 presence 를 다시 등록합니다.

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

멀티플레이는 Supabase Realtime을 쓰며, 연결 실패 시 1인 모드로도 동작합니다.
