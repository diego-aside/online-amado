# 온라인 아마도 (Online Amado)

중앙대 후문 요리주점 '아마도'(서울 동작구 흑석로 10, 1층 2호)를 재현한 온라인 술집 월드.
친구들과 같은 테이블에 앉아 메뉴를 주문하고, 술을 마시며, 취기까지 공유하는 멀티플레이 공간.

> 비공식 팬메이드 재현입니다. 사진 속 인물이나 사장님을 특정하지 않으며,
> 사장님 NPC는 리뷰 언급에 기반한 캐릭터입니다.
> 영업시간·전화번호·현재 가격은 가게에 직접 확인하세요.

## 구성

- `index.html` / `style.css` / `main.js` — 정적 사이트 (Three.js r170 + Supabase Realtime + PeerJS)
- `menu.json` — 메뉴·가격 (출처: 2026-09-10 네이버 플레이스 메뉴판, 2026-11-13 라이브 확인)
- `scenarios.json` — 시나리오 8종 + 사장님 대사
- `VERIFY.md` — 빌드 검증 기록

## 특징

- 다크그린 벽 + 원목 테이블 6개(각 4석)의 3D 룸
- 테이블마다 4자리 비밀코드 — 코드 아는 사람만 입장, 대화·주문·취기는 같은 테이블 안에서만 공유
- 취기 0~5단계 동기화 (술 +1, 물 -1, 화장실 -1, 안주 -0.5). 레벨 5는 무지개 토 🌈
- 앉는 순간 줌형 격자 화면 — PeerJS 화상 (카메라·마이크 기본 OFF)
- 사장님 NPC ("어서 와요, 아미고들!"), 시나리오 8종, 테이블 공유 장바구니 + "내가 쏜다"

## 로컬 실행

```bash
python3 -m http.server 8000
# http://localhost:8000 접속
```

멀티플레이는 Supabase Realtime을 쓰며, 연결 실패 시 1인 모드로도 동작합니다.
